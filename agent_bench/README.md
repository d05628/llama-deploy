# agent 测试题组

用固定的 4 道题无人值守地测试各 CLI agent（接本地模型），自动评分并生成报告。
题目固定、评分规则固定，换模型、换量化、升级引擎或 agent 后重跑即可横向比较。

```bash
python agent_bench/run_bench.py                                   # 所有已安装 agent × 全部题目
python agent_bench/run_bench.py --agents claude,codex --tasks svg,bugfix
```

结果在 `~/llama-agent-workspace/bench/<时间>/`：`report.md`（汇总表 + 明细）、`results.json`、
每个 agent × 题目的工作目录（产物都在里面）和 `logs/`。运行前会自动把模型服务切到
agent + 看图模式，并启动兼容网关。

## 题目

| id | 题目 | 考什么 | 自动检查 |
|---|---|---|---|
| `movie` | 扫描 C 盘以外的硬盘，找名字带「电影」的文件夹，解读任一视频开头一分钟 | 在大硬盘里找文件；抽帧看图（视觉）+ 语音转写；写结构化报告 | 报告存在、引用的视频路径真实存在、至少 3 帧、有按时间的描述 |
| `blender` | 用 Blender 做火柴人动画，导出 30 秒视频 | 调用外部工具、读报错自行修正、渲染验证 | 有视频、时长 28–32 秒、画面在动、留有脚本 |
| `svg` | 鹈鹕骑自行车 SVG（Simon Willison 的经典题） | 纯创意代码生成、空间构图 | 合法 SVG、有一定复杂度；画面好坏需人看 |
| `bugfix` | 修复一个小型发票库里的 bug，让测试全部通过 | 读懂多文件代码、从失败测试定位根因、受约束的最小修改、自行验证 | 8 个测试全过、测试文件未被改动、写了修复说明 |

`bugfix` 是为弥补前三题的盲区设计的：前三题难以客观打分，也没有考到 agent 最常见的日常工作——
在一个现成的代码库里读懂代码、按规格改对。它藏了 3 个不同类型的 bug（二进制浮点下的舍入、
折扣阈值的边界、周末顺延漏了周日），8 个测试里有 5 个失败；测试即规格，不许改。
题目材料在 `fixtures/invoice/`，参考答案刻意不放进仓库。

## 安全

每个工具只放行题目需要的操作，用各自原生的权限机制（均已实测生效）：

| 工具 | 方式 |
|---|---|
| Claude Code | `acceptEdits`（工作目录内改文件自动批准）+ `--allowedTools` 命令白名单 |
| OpenCode | `permission` 规则：按命令放行，其余 `deny` |
| Codex | 自带沙箱 `workspace-write`：只能写工作目录、不能联网 |
| Aider | 不执行命令；只做 `svg` / `bugfix`（测试命令由脚本固定传入） |
| Gemini CLI | **命令白名单在无人值守时不生效**（与 Qwen Code 同源，同样的问题）。只做无需命令的 `svg` |
| Qwen Code | 无人值守模式受限，**整体跳过**：命令白名单不生效（实测只放行 `ffprobe`，`whoami` 照样执行）；主会话里也没有写文件工具（`select:write_file` → Not found），连 `svg` 都写不了文件、15 分钟超时。它在交互式窗口里表现很好，请用「一键启动 Agent」打开后交互式测试，逐条确认命令 |

测试使用独立的配置目录 `agents/bench-<工具>/`，不影响日常配置。
